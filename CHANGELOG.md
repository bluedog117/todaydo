# Changelog

## 0.1.0 — 2026-11-22

Initial public source release.

- Native macOS menu bar app with foreground activity tracking.
- English interface, permissions text, categories, and CSV headings.
- Timelines, weekly/monthly views, trends, project rules, and focus statistics.
- Pomodoro timer, configurable reminders, local snapshots, optional Calendar and iCloud integrations.
- Independent todaydo application identity and storage.
- Build script and 31 synthetic core checks.
