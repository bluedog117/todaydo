# Security

## Reporting

For a suspected vulnerability, avoid posting personal activity data or working exploit details publicly. Use GitHub private vulnerability reporting if it is available on the repository. Otherwise open a minimal issue requesting a private contact route without disclosing sensitive details. No response-time guarantee is offered.

## Sensitive data

Do not attach activity databases, snapshots, full browser URLs, signing certificates, or credentials. Use synthetic examples and remove device names and local account paths from logs.

## Scope

todaydo is a non-sandboxed desktop application. Browser Automation, full Calendar access, notifications, and iCloud Drive each have separate implications. See [privacy documentation](docs/PRIVACY.md). Built apps are currently ad-hoc signed and not notarized.
