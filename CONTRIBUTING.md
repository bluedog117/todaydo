# Contributing

Open an issue describing a reproducible problem or proposed improvement before large changes. Small fixes can be submitted directly as pull requests.

1. Build using [the build guide](docs/BUILD.md).
2. Keep source, interface text, and documentation in English.
3. Run the existing core checks and build affected targets.
4. Describe the behavior changed and the limits of your verification.
5. Use synthetic activity when sharing examples. Never commit databases, CSV exports, snapshots, tokens, signing material, or personal screenshots.

Do not claim that passing core checks proves Calendar, browser, notification, or iCloud behavior. Report manual checks separately.

No hosted CI workflow is currently configured. Contributions are provided under the repository MIT license.
